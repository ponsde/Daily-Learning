phase_3: 
switch 跳转表
主要不知道sscanf的机制
sscanf 接受参数来进行读取
rdi为string，rsi为format，即读取的格式，该题为%d %c %d  因为是d，因此要让十进制的
rdx、rcx、r8作为接受参数
要一一对应，即第一个读取的%d放到rdx、第二个%c放到rcx，以此类推
%rdx 为 0x10(%rsp) 跳转到第几个case

%rcx 为 0xf(%rsp) 作为比较，放对应ascii的字符

%r8 为 0x14(%rsp) 作为比较，放对应ascii的字符

前面的15个字节应该是为了对齐然后空出来的吧，不管它

phase_4:
一遍过！
递归，直接对着func4写了粗糙的算法
int func4(int x)
{
    if (x <= 0)
    {
        return 0;
    }
    a = x
    if (x == 1)
    {
        return 1;
    }
    x -= 1
    int m = func4(x)
    a -= 2
    int n = func4(a);
    return n + 2 * m
}
x:
0 1 2 3 4 5
return:
0 1 2 5 12 29

然后第一个值是循环次数，这里要求是6次，第二个值就是这6次循环结束，func4的返回值加起来即可
